# Python FastPass for C++ Developers

本仓库记录了我从 C++ 背景快速切入 Python 开发的学习笔记与底层思考。

## 出处与致谢

本笔记在学习过程中参考了以下优质资源，并结合个人 C++ 背景进行了扩充与底层逻辑对比：

1. **基础框架参考**：借鉴了[Learn Python in Y Minutes](https://learnxinyminutes.com/zh-cn/python/)的简略教程。原教程提供了 Python 语法的快速索引，非常适合初学者。
2. **深度补全**：针对原教程中较为简略的部分，我进行了语法细节补全、底层原理解析，并补充了 RAG 实战相关的工程细节。
3. **C++ 对比视角**：侧重于 Python `PyObject*` 指针模型、RAII 与 `with` 协议对比、以及内存模型的思维转换。

## 为什么建立这个笔记？

作为一个 C++ 开发者，我发现很多 Python 教程过于偏向应用。我需要一份能够告诉我“底层发生了什么”的笔记，因此有了这份结合了指针思维和内存模型分析的 Python 快速手册。
